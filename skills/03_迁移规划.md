# 技能：迁移规划

## 目的

生成并严格校验迁移计划，让大模型的方案落在 harness 可执行的边界内。

## 触发条件

- 扫描与检索完成后；
- 需要对某个文件或模块制定改造方案时。

## 输入

- 扫描出的文件清单；
- LLM 客户端（OpenAI 兼容或 Ollama）；
- 检索命中的迁移范例。

## 输出

`PlanItem` 列表，每项包含：

- `id`：计划编号；
- `file`：项目内相对路径；
- `issue`：问题描述；
- `action`：`copy` 或 `transform`；
- `impact`：`low`、`medium` 或 `high`；
- `evidence`：决策依据。

## 步骤

1. 将文件清单交给大模型生成 JSON 计划；
2. 按档案 scope 限制允许的改动类别；
3. 按文件数分批调用模型，避免单次响应截断；
4. 校验每条计划的文件、动作、影响面与证据；
5. 引用清单外文件、非法动作或非法影响面的一律拒绝；
6. LLM 失败时回退到逐文件复制计划；
7. 超过 30% 大规模重构阈值时暂停并征得用户同意；
8. 检查计划条目预算。

## 约束

- 模型只负责提出方案，不直接执行；
- 没有证据的 `transform` 计划不得进入应用阶段；
- 对应工具白名单：`propose_plan`。
