# 技能：验证与报告

## 目的

验证迁移输出，生成中文迁移报告，保证任务可追溯、可审查。

## 触发条件

- 计划条目应用完成后；
- 任务收尾需要汇总结果时。

## 输入

- 输出文件；
- `MigrationState`；
- `AuditWorkspace`。

## 输出

- `VerifierResult`：验证结果；
- `report.md`：中文迁移报告；
- 更新后的 `state.json`。

## 步骤

1. 对 Python 文件执行 AST 语法验证；
2. 对其他文件执行存在性与可读性验证；
3. 按 `verification` 配置执行导入检查与白名单命令；
4. 单文件验证失败时删除输出文件并标记 `failed`；
5. 单文件验证通过后标记 `applied`；
6. 收尾行为验证失败且 `fail_on_error: true` 时，任务进入 `failed`；
7. 生成中文报告并保存审计状态。

## 约束

- 验证失败的计划不得标记为 `applied`；
- 报告必须使用中文；
- 报告应包含迁移档案、规则 ID、命中的 API 与证据文档；
- 对应工具白名单：`run_verifier`、`write_report`。
