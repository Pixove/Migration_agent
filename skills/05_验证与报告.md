# 技能：验证与报告

## 目的

验证迁移输出，生成中文迁移报告，保证任务可追溯、可审查。

## 触发条件

- 计划条目应用完成后；
- 任务收尾需要汇总结果时。

## 输入

- 输出文件；
- `MigrationState`；
- `AuditWorkspace`。

## 输出

- `VerifierResult`：验证结果；
- `report.md`：中文迁移报告；
- 更新后的 `state.json`。

## 步骤

1. 对 Python 文件执行 AST 语法验证；
2. 对其他文件执行存在性与可读性验证；
3. 验证失败时删除输出文件并标记 `failed`；
4. 验证通过后标记 `applied`；
5. 生成中文报告并保存审计状态。

## 约束

- 验证失败的计划不得标记为 `applied`；
- 报告必须使用中文；
- 对应工具白名单：`run_verifier`、`write_report`。

## 对应代码

- `tools/verifier.py`
- `tools/reporter.py`
- `agent/loop.py` 的 `_finish`
