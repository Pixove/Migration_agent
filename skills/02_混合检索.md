# 技能：混合检索

## 目的

从最佳实践文档与遗留代码示例中召回迁移范例，为每条迁移决策提供证据。

## 触发条件

- 生成迁移计划之前；
- 需要判断某个 API 或语法在目标版本的替代方案时。

## 输入

- 最佳实践文档路径（TXT、Markdown、PDF，可为文件或目录）；
- 检索配置（BM25、向量、重排参数）；
- 查询语句，如过时 API 名称或抽象迁移意图。

## 输出

`RetrievalHit` 列表，每项包含：

- `document`：命中的文档；
- `score`：得分；
- `source`：来源（`bm25`、`vector` 或 `rerank`）。

## 步骤

1. 使用 `load_documents` 导入文档；
2. 构建 `HybridRetriever`；
3. BM25 精确召回过时 API 相关文档；
4. 向量检索补充语义相关文档；
5. 合并去重后交给 Cross-Encoder 重排；
6. 输出 Top-K 迁移范例。

## 约束

- 文档导入失败必须记录；
- 向量检索依赖未安装时保持关闭；
- 重排依赖未安装时保持原始顺序，不得报错中断；
- 对应工具白名单：`retrieve_examples`。

## 对应代码

- `retrieval/` 整个检索层
- `agent/loop.py` 的 `_retrieve`
