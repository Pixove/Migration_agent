# 项目概览

## 项目定位

Migration Agent 是一个企业级代码库现代化迁移 Agent。用户通过命令行指定
待迁移项目路径与迁移输出路径，由大模型生成迁移方案，由 harness 负责
校验、执行、验证与审计，实现低风险、可追溯的自动化重构。

## 核心目标

- 双路径 CLI：输入项目只读，输出目录唯一可写；
- 大模型生成迁移方案，harness 控制执行边界；
- RAG 混合检索：BM25 精准匹配 + 向量语义检索 + Cross-Encoder 重排；
- 影响面分级审批，验证失败自动回滚；
- 完整审计记录与中文迁移报告。

## 当前能力

已实现：

- 配置加载与校验，支持 OpenAI 兼容服务与 Ollama；
- 路径沙箱、工具白名单、预算、审批分级；
- 任务状态机与审计工作区；
- 扫描、补丁应用、验证、报告工具；
- 文档导入、BM25 检索、向量与重排接口、混合检索；
- 主循环与 CLI 入口。

待接入：

- `ToolDispatcher`：工具名到函数的映射与白名单强制；
- `context_loader`：把 `AGENTS.md`、`rules/`、`skills/` 注入 LLM 上下文；
- 持久化知识库；
- 检索证据注入规划上下文；
- 真实 `transform` 迁移规则。

## 技术栈

- Python 3.13；
- 运行时依赖：`pyyaml`、`requests`；
- 可选依赖：`sentence-transformers`、`pypdf`；
- 测试：标准库 `unittest`。

## 文档体系

- `AGENTS.md`：Agent 行为入口与文件索引；
- `rules/`：运行时行为规则；
- `skills/`：技能使用说明；
- `docs/`：本目录，架构与调试文档。
