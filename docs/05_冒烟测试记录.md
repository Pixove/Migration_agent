# 冒烟测试记录

## 目的

用真实 CLI 做一次端到端迁移，验证骨架流水线从启动到报告全流程可用。

## 测试命令

单元测试：

```bash
.venv\Scripts\python.exe -m unittest discover tests -v
```

真实 CLI 冒烟：

```bash
.venv\Scripts\python.exe main.py --source <临时输入项目> --output <临时输出目录> --no-llm
```

样例项目包含：

- `a.py`：带 UTF-8 BOM 的 Python 文件；
- `utils/b.py`：带 UTF-8 BOM 的 Python 文件；
- `notes.txt`：普通文本文件。

## 运行结果

- 单元测试：17 个全部通过；
- CLI 退出码：0；
- 阶段：`done`；
- 计划条目：3 条，全部 `applied`；
- 审计记录：9 条；
- 输出产物：`a.py`、`utils/b.py`、`notes.txt`、`report.md`、`state.json`。

## 发现并修复的问题

首次冒烟时，PowerShell 写入的 UTF-8 BOM（`U+FEFF`）导致 AST 语法解析失败，
两个 Python 文件被正确回滚并标记为 `failed`。

修复内容：

- 读取源文件时改用 `utf-8-sig` 编码，自动剥离 BOM；
- 验证器与行数统计同步使用 `utf-8-sig`；
- 新增回归测试 `test_bom_source_file_passes_verification`。

修复后重新冒烟，全部计划条目 `applied`，验证通过。

## 结论

骨架流水线闭环验证通过：双路径 CLI、扫描、回退计划、补丁应用、
AST 验证、回滚机制、审计与报告均可正常工作。
