# 配置说明

配置文件为项目根目录的 `config.yaml`，修改后重启 CLI 生效。

## LLM 配置

```yaml
llm:
  provider: openai
  temperature: 0.2
  max_tokens: 2048
  timeout_seconds: 120

  openai:
    base_url: https://api.openai.com/v1
    api_key_env: OPENAI_API_KEY
    model: gpt-4o-mini

  ollama:
    base_url: http://localhost:11434
    model: qwen2.5:7b
```

`provider` 支持 `openai` 与 `ollama`。`openai` 表示任何兼容
OpenAI 协议的服务。DeepSeek 示例：

```yaml
llm:
  provider: openai
  openai:
    base_url: https://api.deepseek.com/v1
    api_key_env: DEEPSEEK_API_KEY
    model: deepseek-chat
```

API Key 通过环境变量提供，不写入配置文件。

## 工作区配置

```yaml
workspace:
  audit_dir_name: .migration-agent
  max_plan_items: 50
  max_retries_per_item: 3
  max_total_patches: 200
```

## 检索配置

```yaml
retrieval:
  bm25:
    enabled: true
    top_k: 20

  vector:
    enabled: false
    top_k: 20
    embedding_model: text-embedding-3-small

  rerank:
    enabled: true
    top_k: 5
    model: cross-encoder/ms-marco-MiniLM-L-6-v2
```

向量检索依赖 `sentence-transformers`，未安装时需保持 `enabled: false`。
