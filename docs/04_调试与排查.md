# 调试与排查

## 常用命令

安装依赖：

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

运行全部测试：

```bash
.venv\Scripts\python.exe -m unittest discover tests -v
```

运行冒烟迁移（不使用大模型）：

```bash
.venv\Scripts\python.exe main.py --source D:\legacy --output D:\migrated --no-llm
```

直接运行单个测试文件必须使用模块方式：

```bash
.venv\Scripts\python.exe -m tests.test_tools
```

## 常见问题

### 报错 No module named 'agent'

原因：直接用脚本路径运行 `tests/test_tools.py`，项目根目录不在
`sys.path` 中。改用 `-m unittest discover tests -v` 或
`-m tests.test_tools`。

### LLM 连接失败

检查：

- `provider` 是否为 `openai` 或 `ollama`；
- `base_url` 是否可访问；
- API Key 环境变量是否已设置；
- Ollama 服务是否已启动。

### 可选依赖缺失

- 向量检索：安装 `sentence-transformers`，或将
  `retrieval.vector.enabled` 设为 `false`；
- PDF 解析：安装 `pypdf`。

### 路径越界

抛出 `GuardrailError` 时，检查计划条目是否使用相对路径，
以及输出路径是否与输入路径重叠。

### 审批卡住

影响面为 `medium` 或 `high` 时会等待人工输入，输入 `y` 继续，
`n` 跳过，输入 `a` 一键同意剩余全部计划；
也可使用 `--auto-approve` 跳过审批。

## 查看审计

任务结束后检查输出目录下的 `.migration-agent/`：

- `state.json`：任务状态与审计记录；
- `audit.log`：运行日志；
- `report.md`：中文迁移报告。

## 排查顺序

1. 确认 `config.yaml` 能正常加载；
2. 运行全部单元测试；
3. 用 `--no-llm` 跑一次最小迁移；
4. 查看 `state.json` 与 `report.md` 定位失败阶段。
