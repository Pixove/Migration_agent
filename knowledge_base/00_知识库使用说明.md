# 知识库使用说明

## 用途

本目录是 Migration Agent 的内置迁移知识库，内容面向 Python 2 到 Python 3
迁移、并发安全、内存泄漏修复与企业级风险控制。

## 导入方式

启动时通过 `--docs` 指向本目录：

```powershell
.venv\Scripts\python.exe main.py --source D:\legacy --output D:\migrated --docs knowledge_base
```

支持多次传入，也可以再追加其他 TXT、MD、PDF 文档目录。

## 文档 ID 约定

每份 Markdown 文件作为一篇文档导入，`doc_id` 为文件名主体。
例如 `01_Python2到3语法迁移.md` 的 `doc_id` 为
`01_Python2到3语法迁移`。

## 检索建议

- 查询过时 API 时使用具体名称，例如 `xrange`、`raw_input`；
- 查询抽象意图时使用场景词，例如 `并发安全`、`内存泄漏`、`死锁`；
- 混合检索会同时做 BM25 精确匹配与语义召回，再经重排输出 Top-K。

## 结构约定

每份文档统一包含：背景、风险、迁移示例（Before/After）、注意事项，
方便 Agent 将具体片段作为 `evidence` 引用。
