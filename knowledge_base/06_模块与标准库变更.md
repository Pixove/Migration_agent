# 模块与标准库变更

## 背景

Python 3 重构了标准库命名与组织方式，许多 `import` 需要调整。

## 网络库

Before:

```python
import urllib2
response = urllib2.urlopen(url)
```

After:

```python
import urllib.request
response = urllib.request.urlopen(url)
```

## 配置解析

Before: `import ConfigParser`

After: `import configparser`

注意：Python 3 的 `configparser` 对默认值与大小写处理更严格。

## 内存流

Before: `from StringIO import StringIO`

After: `from io import StringIO`

## 队列

Before: `import Queue`

After: `import queue`

## 惰性迭代

Before:

```python
from itertools import ifilter, imap, izip
```

After:

```python
filtered = filter(pred, items)
mapped = map(func, items)
zipped = zip(items, other)
```

Python 3 内置 `filter`、`map`、`zip` 均返回惰性迭代器。

## execfile 与 reload

Before:

```python
execfile('config.py')
reload(module)
```

After:

```python
exec(open('config.py').read())
import importlib
importlib.reload(module)
```

## reduce

Before: `reduce(func, items)`

After: `from functools import reduce`

## 注意事项

迁移导入语句后必须运行测试，确认新库行为与旧库一致；
部分库（如 `ConfigParser`）行为差异需要单独适配。
