# py3_upgrade 知识库使用说明

本目录是 `py3_upgrade` 档案的默认知识库，覆盖 Python 3.x 版本升级
中的废弃 API、新语法与性能注意事项。

使用方式：

```powershell
.venv\Scripts\python.exe main.py --source D:\legacy --output D:\migrated --docs knowledge_base/py3_upgrade
```

或将 `config.yaml` 的 `migration.profile` 改为 `py3_upgrade` 后
不传 `--docs`，主循环会自动加载本目录。
