# 性能与新语法

## Python 3.11+ 性能

- Python 3.11 起解释器执行性能显著提升；
- 升级后应运行基准测试，验证真实收益；
- 性能敏感代码可配合 `asyncio`、`functools.lru_cache` 进一步优化。

## match 语句（Python 3.10+）

长串 `if/elif` 可用 `match` 改写，但需要人工确认语义等价：

Before:

```python
if kind == 'a':
    ...
elif kind == 'b':
    ...
```

After:

```python
match kind:
    case 'a':
        ...
    case 'b':
        ...
```

## zoneinfo（Python 3.9+）

常见时区场景可用标准库 `zoneinfo` 替代第三方库：

```python
from zoneinfo import ZoneInfo
```
