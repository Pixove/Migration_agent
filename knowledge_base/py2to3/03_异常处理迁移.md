# 异常处理迁移

## 背景

Python 3 清理了异常语法并引入更完善的异常链，迁移时应同步调整
异常捕获与抛出方式。

## except 语法

Before:

```python
except IOError, e:
    print e
```

After:

```python
except OSError as e:
    print(e)
```

注意：`IOError` 已并入 `OSError`。

## 禁止抛出字符串

Before: `raise 'failure'`

After: `raise ValueError('failure')`

Python 3 不再支持以字符串作为异常抛出。

## 异常链

需要保留原始异常时使用 `raise ... from`：

```python
try:
    value = int(raw)
except ValueError as exc:
    raise ConversionError('invalid value') from exc
```

## with 替代 try/finally

Before:

```python
f = open(path)
try:
    process(f)
finally:
    f.close()
```

After:

```python
with open(path) as f:
    process(f)
```

风险：迁移后必须确认资源在异常路径下同样被释放。

## 注意事项

- 异常变量在 `except` 块结束后不再可用；
- 捕获异常范围宁窄勿宽；
- 迁移后应保留原有错误码与日志格式，避免破坏外部约定。
