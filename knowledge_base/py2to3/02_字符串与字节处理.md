# 字符串与字节处理

## 背景

Python 2 中 `str` 表示字节串，`unicode` 表示文本；Python 3 中
`str` 表示文本，`bytes` 表示字节串。迁移后最容易出现编码错误。

## 字面量

Before:

```python
data = 'utf-8 bytes'
text = u'中文'
```

After:

```python
data = b'utf-8 bytes'
text = '中文'
```

## 编码转换

文本转字节：

```python
data = text.encode('utf-8')
```

字节转文本：

```python
text = data.decode('utf-8')
```

风险：混用 `str` 与 `bytes` 时 Python 3 会抛出
`TypeError: can't concat str to bytes`，必须显式转换。

## 文件读写

- 文本模式读取指定编码：`open(path, encoding='utf-8')`；
- 二进制数据使用 `rb` / `wb`；
- 不要对二进制内容直接调用 `read().decode()` 之外的隐式转换。

## JSON

Before:

```python
json.dumps(data)
```

After:

```python
json.dumps(data, ensure_ascii=False)
```

风险：默认 `ensure_ascii=True` 会把中文转义为 `\uXXXX`，
写入文件时应显式控制编码。

## 注意事项

- 网络、文件、数据库边界是编码错误高发区；
- 迁移后使用包含中文、特殊符号的样本做回归；
- 明确每个接口约定输入是 `str` 还是 `bytes`。
