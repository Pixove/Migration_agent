# 测试迁移正确性

## 背景

语法迁移只是第一步，行为等价才是迁移成功的关键。

## 黄金用例

为每个迁移规则准备 Before/After 黄金用例：

```python
def test_print_statement():
    source = "print 'hello'"
    assert transform(source) == "print('hello')"
```

## 输出等价

对典型输入执行迁移前后代码，对比输出：

- 控制台输出；
- 文件内容；
- 返回值；
- 异常类型与消息。

## 边界输入

覆盖边界输入：

- 空字符串与空列表；
- 中文与特殊字符；
- 大文件与超长行；
- 嵌套异常与并发场景。

## 回归套件

规则集每次扩展后必须运行全部历史用例，防止修复 A 破坏 B。

## CI 集成

建议在 CI 中执行：

```bash
.venv\Scripts\python.exe -m unittest discover tests -v
```

## 注意事项

测试通过不代表行为完全等价，关键模块还应做人工审查与灰度验证。
