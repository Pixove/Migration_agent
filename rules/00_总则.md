# 总则

## 目的

本文档定义 Migration Agent 在运行时的行为边界，确保大模型驱动的迁移任务
始终在低风险、可验证、可追溯的范围内执行。

## 适用范围

- Agent 的规划、应用、验证与报告阶段；
- 所有写入输出目录的生成物；
- 所有需要调用模型或工具的决策点。

## 规则优先级

1. 代码层强制护栏（路径沙箱、工具白名单、预算、审批）优先；
2. 其次为本目录下的规则文档；
3. 最后为 `skills/` 中的技能说明。

## 基本原则

- 输入项目只读，输出目录是唯一可写区域；
- 模型只负责提出方案，harness 负责校验与执行；
- 每条迁移决策必须有依据，禁止无证据修改；
- 每条变更应用后必须验证，验证失败必须回滚；
- 所有关键动作必须写入审计记录，保证可追溯。

## 文档语言

项目内所有规则、技能与报告文档默认使用中文。
