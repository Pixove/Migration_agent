# 工具使用规范

## 工具白名单

Agent 只能调用以下工具：

- `scan_files`：扫描输入项目文件；
- `retrieve_examples`：从最佳实践文档中召回迁移范例；
- `propose_plan`：生成并提交迁移计划；
- `apply_patch`：在输出目录内应用计划条目；
- `run_verifier`：验证输出文件；
- `write_report`：生成迁移报告；
- `read_document`：按需读取 `rules/` 与 `skills/` 文档；
- `propose_edit`：生成语义编辑 diff 预览，不写文件；
- `apply_edit`：应用语义编辑到输出目录，`medium/high` 需人工审批。
- `read_source`：按需读取输入项目源文件，只读、不可越界。

## 调用约束

- 模型不得直接执行 shell 命令；
- 模型不得直接读写文件系统；
- 工具白名单之外的调用一律拒绝；
- 每个工具必须按定义的参数结构调用；
- 工具失败必须记录错误，不得静默忽略。

## 失败处理

- 单条计划应用失败时标记为 `failed` 并记录原因；
- 验证失败时回滚输出文件；
- LLM 计划生成失败时回退到复制计划，并写入审计记录。
