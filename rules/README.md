# 规则模块

本目录存放 Migration Agent 的**运行时行为规则**，用于约束 Agent 在
扫描、规划、编辑、验证和收尾阶段的行为边界。它是 AI Agent 的行为
说明，不是程序入口，也不包含可执行逻辑。

不要把本目录与 `migration/rules/` 混淆：

- `rules/`：行为规则、权限边界、审批与审计要求；
- `migration/rules/`：机器可读的 API 迁移规则表，由 AST 扫描器读取。

## 阅读顺序

1. 每次任务先读 `AGENTS.md`，获取入口说明与文件索引；
2. 必读 `00_总则.md`，确认规则适用范围与优先级；
3. 涉及路径、工具、决策、验证、审计时，按需读取 `01` 至 `05`；
4. 需要具体操作方法时，再读取 `skills/` 下对应技能文档。

## 文件索引

| 文件 | 内容 | 读取时机 |
| --- | --- | --- |
| `00_总则.md` | 模块目标、适用范围、规则优先级、基本原则 | 每次任务必读 |
| `01_路径与权限边界.md` | 输入只读、输出唯一可写、路径沙箱、禁止行为 | 涉及路径或文件操作时 |
| `02_工具使用规范.md` | 工具白名单、调用约束、失败处理 | 执行任何工具前 |
| `03_迁移决策规范.md` | 证据要求、影响面分级、30% 重构阈值、预算 | 生成或评审计划时 |
| `04_验证与回滚规范.md` | 应用前检查、应用后验证、失败回滚 | 应用变更时 |
| `05_审计与报告规范.md` | 审计目录、记录字段、报告要求、可追踪性 | 任务收尾时 |

## 规则优先级

1. harness 代码中的硬约束最高：路径沙箱、工具白名单、预算、审批；
2. 本目录下的规则文档次之；
3. `skills/` 中的技能说明再次；
4. `docs/` 中的架构与设计文档仅作背景说明。

任何规则都不能与代码实现冲突。如果文档与代码行为不一致，应先确认
代码的真实约束，再同步修正规则文档，不能反过来绕过代码护栏。

## 核心红线摘要

- 输入项目只读，输出目录唯一可写；
- 不调用白名单以外的工具或 shell 命令；
- 无证据不得替换、删除或重写代码；
- `medium/high` 影响必须人工审批；
- 验证失败的改动必须回滚，不得标记为已应用；
- 重构比例超过 30% 必须暂停并取得用户同意；
- 不把 API Key 等敏感信息写入配置或提交；
- 不跳过审计记录，不伪造审计内容。

完整红线以 `AGENTS.md` 为准。

## 修改规则的要求

- 新增、删除或重命名规则文档时，同步更新 `AGENTS.md` 的文件索引；
- 规则内容必须与 `agent/guardrails.py`、`agent/agentic.py`、`tools/` 的
  实际行为一致；
- 影响执行逻辑的规则变更，必须补充或更新 `tests/`；
- 文档统一使用中文，避免模糊表述；
- 不新增与现有规则重复或冲突的条目。

## 关联文档

- `skills/`：具体能力的操作说明；
- `migration/rules/README.md`：API 迁移规则表说明；
